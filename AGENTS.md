- **Files Modified**:

- **Feature Details**:
  - **flipSequence** (`js/Track.js`): Mirrors notes left-to-right across the sequence center column
    - Returns early for Audio tracks (no sequencer data)
    - Validates active sequence exists, returns if not
    - Uses `halfCols = Math.floor(totalSteps / 2)` to iterate only half the columns
    - Swaps `row[col]` with `row[mirroredCol]` where `mirroredCol = totalSteps - 1 - col`
    - Counts all active notes (left + right) for the return value
    - Calls `_captureUndoState` with descriptive label "Flip Sequence {name}"
    - Calls `recreateToneSequence(true)` and `updateTrackUI` on success
  - **Flip Sequence menu item** (`js/ui.js`): Added to sequencer context menu after "Reverse Sequence"
    - Captures undo state before flipping
    - Calls `track.flipSequence()` and handles result > 0 case
    - Shows "Flipped {count} note(s)." notification on success
    - Shows "No notes to flip." notification when nothing to flip
    - Calls `recreateToneSequence(true)` and `updateTrackUI` on success
  - **Tests** (`js/tests.js`): 17 tests covering:
    - `flipSequence` is a function on Track.prototype
    - `flipSequence` accepts 0 parameters
    - Returns 0 for Audio track type
    - Gets active sequence via `getActiveSequence`
    - Returns 0 if no active sequence
    - Uses `halfCols` calculation with `Math.floor` for mirroring
    - Swaps left and right cells via `mirroredCol`
    - Calls `_captureUndoState` for undo support
    - Returns `flippedCount`
    - Menu item exists in sequencer context menu
    - Menu item calls `track.flipSequence`
    - Menu item captures undo state
    - Menu item calls `recreateToneSequence` after flip
    - Menu item shows notification with flipped count
    - Menu item handles no notes case
    - APP_VERSION validation (>= 2.201 for Day 543)
